# kitty themes

The team's kitty colour themes. Any `.conf` in here shows up in `k-theme`'s All tab, with a
live preview, next to kitty's own collection; `ctrl-a` in the picker adds it to your Mine list.
`k-theme add <file or URL>` imports a theme for just you (into `~/.config/kitty/themes/`).

Only the colour lines of a theme are used (`foreground`, `color0`..`color255`,
`cursor`, tab colours, ...), so a theme can't change any other kitty setting.
